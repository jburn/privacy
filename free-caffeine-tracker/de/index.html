Free Caffeine Tracker — Datenschutzerklärung

Gültig ab: 8. November 2026

Auf Ihrer Uhr gespeicherte Daten

Free Caffeine Tracker wird von Bruun Software entwickelt. Die App speichert protokollierte Getränke, Koffeinmengen, Zeitstempel, Lieblingsgetränke, Einstellungen und zusammengefasste Verbrauchsdaten lokal auf Ihrer Uhr. Ein kleiner lokaler Datenstand unterstützt Kurzansichten und Anzeigen auf Zifferblättern.

Die Details der nach Konsumzeitpunkt 256 neuesten Getränke bleiben erhalten. Ein zusätzliches, zuletzt protokolliertes Getränk kann für die Rückgängig-Funktion gespeichert bleiben. Älterer Konsum wird zusammengefasst.

Die App übermittelt diese Informationen nicht an Bruun Software. Bruun Software hat keine Kopie Ihres Getränkeverlaufs auf einem Server.

Offlinebetrieb und Zugriff

Die Protokollierung und Koffeinschätzungen funktionieren offline. Die App hat keine Konten, Werbung, Analysefunktionen, Internetzugriff, Telefonkommunikation oder Zugriff auf Standort, Sensoren oder Gesundheitsprofil.

Hintergrundaktualisierungen und Zifferblätter

Auf unterstützten Uhren aktualisiert ein Hintergrunddienst die lokalen Schätzungen. Die aktuelle Koffeinmenge, die heutige Aufnahme und die Schätzung zur Schlafenszeit stehen kompatiblen Zifferblättern über Garmins Komplikationssystem zur Verfügung. Andere Zifferblätter haben eigene Datenschutzpraktiken.

Verwaltung Ihrer Daten

Sie können kürzlich erfasste Getränke bearbeiten oder löschen, das letzte Getränk rückgängig machen und den Verlauf in den Einstellungen löschen. Favoriten und Einstellungen lassen sich ebenfalls auf der Uhr ändern.

Garmin-Dienste und Website-Hosting

Garmins Store und Plattformdienste sind von der App getrennt und unterliegen Garmins Datenschutzerklärungen.

Diese Datenschutz-Website wird auf GitHub Pages gehostet. GitHub betreibt den Hostingdienst und kann Informationen über Websitebesuche gemäß seinen eigenen Datenschutzpraktiken verarbeiten.

Kontakt für Datenschutz und Support

Informationen, die Sie freiwillig per Support-E-Mail senden, sind von den lokalen Daten der App getrennt.

Bei Datenschutz- oder Supportfragen schreiben Sie an bruunsoftware@gmail.com.
