Free Caffeine Tracker — Privatlivspolitik

Gældende fra: 8. november 2026

Data gemt på dit ur

Free Caffeine Tracker udvikles af Bruun Software. Appen gemmer registrerede drikke, koffeinmængder, tidsstempler, favoritdrikke, indstillinger og opsummeret forbrugshistorik lokalt på dit ur. Et lille lokalt øjebliksbillede understøtter oversigtsvisninger og aflæsninger på urskiver.

Detaljerne for de 256 nyeste drikke efter indtagelsestidspunkt bevares. Én yderligere senest registreret drik kan bevares til Fortryd. Ældre indtag opsummeres.

Appen sender ikke disse oplysninger til Bruun Software. Bruun Software har ingen serverkopi af din drikkehistorik.

Offlinefunktion og adgang

Registrering og koffeinestimater fungerer offline. Appen har ingen konti, reklamer, analyseværktøjer, internetadgang, telefonkommunikation eller adgang til placering, sensorer eller sundhedsprofil.

Baggrundsopdateringer og urskiver

På understøttede ure opdaterer en baggrundstjeneste lokale estimater. Aktuel koffeinmængde, dagens indtag og estimatet ved sengetid er tilgængelige for kompatible urskiver via Garmins komplikationssystem. Andre urskiver har deres egen praksis for privatliv.

Administration af dine data

Du kan redigere eller slette de seneste drikke, fortryde den sidste drik og rydde historikken i Indstillinger. Du kan også ændre favoritter og indstillinger på uret.

Garmins tjenester og webhosting

Garmins butik og platformstjenester er adskilt fra appen og er underlagt Garmins privatlivspolitikker.

Denne hjemmeside med privatlivspolitikker hostes på GitHub Pages. GitHub driver hostingtjenesten og kan behandle oplysninger om besøg på hjemmesiden efter sin egen praksis for privatliv.

Kontakt om privatliv og support

Oplysninger, som du frivilligt sender via supportmail, er adskilt fra appens lokale data.

Ved spørgsmål om privatliv eller support kan du skrive til bruunsoftware@gmail.com.
